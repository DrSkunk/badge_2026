## Getting started

The badge runs a customised version of
[MicroPythonOS](https://github.com/Fri3dCamp/badge_firmware_MicroPythonOS).

It comes with several
[pre-installed applications](https://docs.micropythonos.com/apps/built-in-apps/)
and an
[App Store](https://docs.micropythonos.com/apps/appstore/)
where you can find and install additional programs.

You can also write your own applications using MicroPython and the
[Fri3d IDE](https://fri3dcamp.github.io/Fri3d-IDE/).

[Learn how to write programs for the badge](programming.md)

## Restore the standard firmware

Does your badge no longer start, or do you want to restore the original
software?

Visit the badge or soldering tent, where you will find the badge repair
station. The computer there provides step-by-step instructions for flashing
the original firmware back onto all supported boards.

You can also
[restore the standard firmware yourself](https://fri3dcamp.github.io/fri3d-web-flasher/).
